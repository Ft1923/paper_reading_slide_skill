# 论文逐段精读：用户的规则与经验积累

逐段精读讲义按本仓库 `paper-deep-read-slides/SKILL.md` 的要求制作。下面是用户在使用过程中提出、以后每篇文章都要遵守的补充规则；与 SKILL.md 冲突时，以本文件为准。

## 经验 0：新加的页面一律白底、直接贴图，不做排版（来自 Ding et al., Nat. Energy 2026，2026-11-24 起）
- 用户原话：“后面做 PPT 的时候不用考虑排版，直接用白的背景，贴图贴图贴图，不用考虑任何排版美观的事情，我们省一些。”
- 做法：白色背景；图片按顺序直接放上去，配必要的简短文字；不做卡片、配色、对齐、反复截图微调等美观工作。公式仍按经验 4 用 LaTeX 图片。
- 已有页面不需要回头改成白底，除非用户要求。

## 经验 1：图紧跟引用它的段落（来自 Lee et al., Nat. Commun. 2026）
- 某一段引用了正文图（如 Fig. 2b），**下一页就立即给出这张图**，并且读图解读要**针对这一段**：先说这段在讲什么，再说看图哪里、读出什么、注意什么。
- 不要把一个小节引用的图集中放在小节末尾统一解读。
- 同一张图被多段引用时，每段后面各放一页，各自用突出不同部分的标注版本；第一次出现时讲清坐标轴的读法，之后只讲本段用到的那一点。
- 一段引用多张图时，按引用顺序依次紧跟；方程页放在图页之后。
- 制作时用脚本列出“段落 → 下一页”的对应关系，逐一核对。

## 经验 2：段落的论证依赖补充图时，补充图也要展示（来自 Lee et al., Nat. Commun. 2026）
- 某段的关键论点只有补充图（Supplementary Fig.）支撑、正文图里看不到时，也要在该段后面紧跟一页展示并解读这张补充图，规则同经验 1。
- 开始精读前就要拿到 Supplementary Information（补充材料 PDF）。如果用户只给了正文，先请用户一起上传补充材料。
- 判断“需要”的标准：这一段的论点是否只能靠补充图来理解或验证（例如 Cu 表面氧化物的分布、首充时界面层的变化）。只是顺带提及的补充图可以不放。
- 用户要求“去 SI 中找数据并分析”时：取作者的 Source Data（源数据表）重算，优先比较同一谱/同一样品内的比值（不受样品间强度差异影响），检查重复测量的一致性，并做量级核算（例如表面吸附量与体相变化是否匹配）。最后用一页表格对照“作者结论 / 源数据显示 / 判断”。

## 经验 3：评论的回答必须写进讲义（来自 Lee et al., Nat. Commun. 2026）
- 除非用户特别说明“只回答就行”，对讲义评论的回答**一定要同时体现在 PPT 里**，不能只回复在评论区。用户说“只回答”时，只在评论区回复，不改 PPT。
- 放在哪里：针对某一段的概念问题，在该段后面紧跟一页“概念补充”；较大的基础概念放到讲义末尾的“补充讲解”小节；“这张图怎么算出来的”放在那张图后面一页。
- 评论区的回复简要说明改了哪一页、核心答案是什么即可。

## 经验 4：所有数学表达式一律用 LaTeX 排版（来自 Lee et al., Nat. Commun. 2026；Ding et al., Nat. Energy 2026 再次强调）
- 讲义里的公式（方程页、概念补充、补充讲解、表格里的式子）都用 LaTeX 书写，再渲染成图片放进幻灯片（Slides 不能直接写 LaTeX：用 MathJax 把 LaTeX 转成 SVG 上传；深色底用浅色公式，浅色底用深色公式）。**不要再用 R_b、I_SS 这种纯文本写法。**
- **Slides 的限制：图片只能作为独立的块元素显示。** 放在文字行内或表格单元格（`<td>`）里的图片会显示成 “[image]”。所以：
  - 含公式的“表格”要用 div 网格来做，公式列放独立的 LaTeX 图片；
  - 正文、说明文字里不要夹带符号，改用文字描述（如“稳态电流”“电解液电阻”），所有符号和式子集中放到公式图片里。
- 自绘示意图里的符号用 matplotlib 的 mathtext（LaTeX 语法）。
- 评论区回复里的公式也写成 LaTeX（如 `$\varphi = E_{\mathrm{vac}} - E_{\mathrm{F}}$`）。

## 经验 5：要求画图时必须画，并画在指定位置（来自 Lee et al., Nat. Commun. 2026）
- 用户说“画图表示”，就自己绘制示意图，不能只用文字解释。
- 用户说“在这张图上画”，就直接画在原来那一页上，而不是另起一页。
- 用户听不懂时，用一个具体对象（如“一个 Na⁺ + 三个氧的配合物”）把过程分格画出来，每格只讲一件事。

## 经验 6：截图必须完整，不能漏掉坐标轴（来自 Lee et al., Nat. Commun. 2026）
- 截取正文图或补充图时，必须保留面板字母、所有坐标刻度数字、坐标轴标题（包括右侧第二纵轴）、色标和图例。
- 截完后自动检查每张图四边约 3 像素内是否有深色像素；碰到边的地方要放大核对，被切的就扩大裁剪框（已有标注用的相对坐标要同步换算）。
- 如果原图本身就被截断（例如作者 SI 里某个刻度数字只印了一半），要在讲义里说明，而不是当作自己裁剪的问题。

## 经验 7：回答要讲到“怎么用、怎么做”（来自 Lee et al., Nat. Commun. 2026）
- 讲方法或物理量时，覆盖：定义、单位、物理意义、怎么看、能看出什么、适用场景与局限，以及“如果我要做，应该怎么做”（步骤与参数）。
- 例：DRT 讲到测 EIS、Kramers–Kronig 检验、正则化反演、选 λ、指认峰、积分定量；三电极讲到电极接法、运行与阻抗参数、为什么要这么做。

## 读者常问的概念：用补充讲解小节回答
- 读者在评论中问基础概念（如范德华色散作用、电荷各向同性、成核过电位、功函数）时，在讲义末尾加一节“补充讲解”，或在相关页后紧跟“概念补充”：自画示意图 + 读图步骤 + 控制方程 + 与本文的关系。
- 读者问某张图是怎么得到的，就在那张图后面紧跟一页说明方法、公式和需要留意的地方。
