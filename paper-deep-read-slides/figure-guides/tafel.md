# Tafel 图读法

## 这张图测什么
在平衡（开路）电位附近慢速扫描，把电流取对数对过电位作图，得到反应动力学参数：交换电流密度 j₀、Tafel 斜率 b。锌电池文献也常用它外推“腐蚀电流”“腐蚀电位”。

## 核心公式
- Butler–Volmer：j = j₀[exp(α_aFη/RT) − exp(−α_cFη/RT)]
- |η| ≳ 50–100 mV 时只剩一项：η = a + b·log|j|（Tafel 方程）
- α = 0.5、n = 1、25 °C 时 b ≈ 118 mV/dec
- j₀：平衡时正、逆反应各自的速率（净电流为 0），越大反应越“容易”

## 坐标轴与常见形式
- 横轴：E 或 η；纵轴：log|j|。曲线呈“V”字，最低点在平衡/腐蚀电位。

## 读图步骤
1. 确认扫速（通常 1–5 mV/s）、扫描范围、是否 iR 补偿。
2. 找两侧的直线段（Tafel 区），读斜率。
3. 两条直线外推到 η = 0（或腐蚀电位），交点纵坐标 = log j₀（或 log j_corr）。
4. 比较不同样品时，看 j₀、j_corr 差多少个数量级，以及斜率是否相近（机理是否相同）。

## 关键特征 → 含义
| 图上的特征 | 物理含义 |
|---|---|
| V 字底部位置 | 平衡电位 / 混合电位（腐蚀电位） |
| 直线段斜率 | Tafel 斜率，反映速控步与传递系数 |
| 外推交点 | j₀ 或 j_corr |
| 直线段很短或弯曲 | 有传质限制、多个反应叠加或欧姆压降 |

## 标注建议
- 两条外推虚线 + 交点圆点，标“j₀”。
- 在直线段旁写斜率数值；在偏离直线处标“混合反应 / 传质影响”。
- 并排放一张线性坐标的 Butler–Volmer 曲线帮助理解。

## 常见陷阱 / 可以追问的地方
- 在金属沉积/溶解与析氢同时发生的电位下，电流分不开，外推出的“腐蚀电流”混合了多个反应。
- 传质限制会扭曲直线段；直线段跨度不足一个数量级时外推不可靠。
- 腐蚀电位是混合电位，不是平衡电位。
- 只报 j₀ 不报斜率、不报扫速，无法比较。

## 案例库

### Baffour et al. 2026, JACS — 引言第 3 段（无图，方法批评）
- 体系：锌晶面工程文献普遍用 Tafel 外推比较 (002) 与其他晶面的副反应活性。
- 作者的解读：两大缺陷：①锌氧化还原电流与副反应电流分不开；②耦合传质限制使动力学参数不可靠。改用“锌沉积前的电位窗口 + RDE + K–L 分析”。
- 读法收获：看到用 Tafel 外推的“腐蚀电流”比较不同电极时，追问：电流是否只来自目标反应？传质是否被扣除？
