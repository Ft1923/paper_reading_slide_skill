# 图表读法库（电化学 / 电池论文）

每种图一份读法。精读论文、给图加标注时，先打开对应的文件，按“读图步骤”讲，按“标注建议”画，再对照“常见陷阱”提出追问。

每读完一篇论文，把新的经验追加到对应文件末尾的 **案例库** 里；遇到新的图类型，就复制 `_TEMPLATE.md` 新建一份，并在下表登记。

## 通用约定

- 先看坐标轴：量、单位、方向（电位轴有时从右往左变负；XPS 结合能轴通常从左往右减小）。
- 再看图例和测试条件：电极、电解液、参比电极、扫速/电流密度/转速、温度。
- 标注颜色在一篇论文内保持一致，和讲解里的区间、路线颜色对应。
- 参比电极换算：Ag/AgCl（饱和 KCl）≈ +0.197 V vs SHE；SCE ≈ +0.241 V vs SHE；Zn²⁺/Zn ≈ −0.76 V vs SHE。

## 如何追加经验

在对应文件末尾的“案例库”里按下面格式加一条：

```
### 作者 年份, 期刊 — 图 X
- 体系：电极 / 电解液 / 条件
- 图上看到什么：……
- 作者的解读：……
- 我的判断 / 追问：……
- 读法收获（可回填到上面的通用读法）：……
```
